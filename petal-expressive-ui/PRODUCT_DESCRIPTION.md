## Long description

**Stop hand-polishing every screen.** Petal Expressive UI Skill packages the design system behind Petal Browser into a skill file your AI coding assistant can follow, with the exact Compose code it needs to copy.

Install the skill, tell your assistant "redesign my app", and it starts by asking you what to redesign: containment, header, icons, predictive back, intro animation, toggles, sliders, animations, shapes, bottom navbar, loading indicator, dialogs, or everything. It then scans your project, confirms a plan, adds only the files that plan needs, converts your screens one at a time and verifies the build.

### What you get
- **SKILL.md** - the guided procedure: project scan, a multi-choice "what do you want redesigned?" interview, scoped execution, verification checklist and hard rules (UI layer only, no logic changes).
- **Grouped containment system** - connected rows with 28dp outer and 6dp inner corners, section labels, toggle rows, control rows, press-squash feedback.
- **Collapsing Petal header** - animated title swap, tonal-to-filled back button morph.
- **Predictive back host with depth blur** - live gesture preview, corner clipping, parallax, dim and blur of the screen behind, committed/cancelled hand-off without flicker, user-toggleable.
- **Floating expressive bottom navbar** - morphing selected pill, bouncy label reveal, rotation accents, haptic tick.
- **Intro animation** - procedural glyph stream with Material You glow and branded headline, plays once per launch.
- **Connected toggle button groups** and **pill buttons** that morph on press.
- **Two sliders** - the signature rolling-cookie slider and a stock-based expressive slider with steps and colours.
- **Motion helpers** - staggered spring entrance, bouncy press states.
- **49 expressive shapes** - the complete 35-shape Material 3 Expressive set plus 14 extras, with a ready catalog.
- **Contained loading indicator** - indeterminate and determinate, plus uncontained and badge variants; replaces every progress bar.
- **Expressive dialogs** - alert dialog and a welcome-dialog template.
- **132 vector icons** curated from the Petal apps.
- **Showcase screen and app shell** that wire everything together.
- **Integration guide** - dependencies, opt-ins, manifest flag, package rename, component migration table, pitfalls.

### Who it is for
Indie Android developers, agencies and studios who want a modern, distinctive Material 3 Expressive UI without designing a component library, and teams that already use AI coding assistants.

### Why it saves time
A typical screen redesign (header, grouped settings, toggles, loaders, dialogs) becomes a guided, repeatable conversion instead of a manual rewrite. The interview step means the assistant never redesigns more than you asked for.

### Compatibility
Jetpack Compose, Kotlin 2.0+, Compose BOM 2026.06.01, Material 3 1.5.0-alpha17 (pinned), `minSdk` 26+, `compileSdk` 35+. Predictive back animations use Android 13+ system support; depth blur needs Android 12+ (graceful fallback below). Not for XML-view-only projects (the skill offers a screen-by-screen migration instead).

### FAQ
**Does it work with my AI tool?** The skill is a plain `SKILL.md` with relative references, usable by any assistant that supports skills or by pasting it as instructions.
**Will it rewrite my business logic?** No. The rules restrict it to the UI layer and require confirmation before it starts.
**Can I redesign only one thing, for example just the loader?** Yes. Pick any subset in the first question.
**Do I need Material 3 expressive APIs?** Yes; the guide shows the exact version pin and opt-ins.
**What about updates?** The 1.5 Material 3 line is pre-release; updates track new versions.
